# javascript_practice

This folder contains examples of various JavaScript concepts including:
- **Functions**: Different ways to define and use functions
- **String Handling**: Operations like slice, split, indexOf, etc.
- **Data Types**: Exploring JavaScript data types and typeof operator
- **For Loop**: Demonstrating for loop with condition
- **Do-While Loop**: Example of do-while loop
- **If-Else Condition**: Conditional statements
- **Array**: Array operations including filter, map, reduce, sort
- **Comments**: Examples of one-liner and multi-liner comments
